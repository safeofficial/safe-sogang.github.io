📋 보고서 추가

구글 드라이브에서 공유 → 링크가 있는 모든 사용자 → 뷰어로 바꿔야 외부 사람도 열립니다.
용량이 큰 리포트(10MB 이상)는 이쪽을 쓰는 게 좋습니다.
사이트에 직접 올립니다. 드라이브 권한 설정 실수로 안 열리는 사고가 없어집니다.
무료 저장 공간이 1GB라 10MB 이하를 권장합니다.

👤 멤버 추가

학회장 → 부학회장 → 회계부장 → PR부장 순으로 맨 위에 왼쪽부터 고정됩니다.
그 외 학회원은 아래쪽에 가나다순으로 정렬됩니다.
🔒 전체 학번은 임원진만 볼 수 있습니다. 웹사이트에는 학번 두 자리만 나갑니다.
같은 사람이 여러 기수로 등록돼도 이름 + 학과 + 학번이 같으면 총 멤버 수에서 한 명으로 셉니다.

📢 공지 추가
